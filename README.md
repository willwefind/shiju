# 拾句

在任意网页上选中一段文字，把它排成一张纸上的摘录，存到本地。
不选文字也行 —— 开一张白纸，日记随笔直接在里面写。

Claude、ChatGPT、小红书、SillyTavern、任何网页都能用。

## 装

需要 **Tampermonkey（篡改猴）**。Chrome 和 Edge 都有，扩展商店搜得到。

1. 油猴面板 → **添加新脚本** → 把 [`shiju.user.js`](shiju.user.js) 的内容整个粘进去 → `Ctrl+S`
2. 或者把 `shiju.user.js` 拖进浏览器窗口，油猴会弹安装页

> Chrome 138+ / Edge 需要在扩展详情页打开 **「允许用户脚本」** 开关。
> 装完记得 **刷新页面** —— 用户脚本只在页面加载那一刻注入。

## 用

- 选中一段文字 → 旁边冒出 **「摘」** → 点它
- 或者选中后按 **`Alt + Q`**
- **什么都不选也行**：按 `Alt + Q`，或油猴菜单 → 「拾句：写点什么」

面板分五屏：

| 屏 | 里面有 |
|---|---|
| **文** | 标题（字号/字重）· 内容 · 出处 · 日期 · 题头 · 三道线开关 |
| **纸** | 内置四张 + 你导入的素材包 + 你自己加的图，**全是缩略图，看图选**；纸张明暗 |
| **字** | 正文 / 西文 / 标题三档，**每一行用它自己的样子写出自己的名字** |
| **色** | 11 支预设墨 + 自己调色（可起名存下来）· 墨色明暗 · 字重 |
| **版** | 版式预设 · 横排竖排 · 对齐 · 纸张方向 · 拆成几张 · 字号 · 整块位移 |

存到 `浏览器下载目录/摘录/`。想换文件夹：油猴菜单 → 「设置保存子目录」。

## 它能做的

**竖排** —— 字从上往下、列从右往左，题头立右边、出处日期立左边。
标点分三类各自处理：`。，、` 挪到格子右上角，`「」（）—…` 转 90°，
英文整串顺时针转 90° 所以读起来是正的。**正文和标题的排向可以分开选。**

**多页拆分** —— 内容多了不必挤一张纸。选「自动」按标准信纸装满几张算几张；
指定张数会尽量平均（40 行分 3 张 = 13/13/14）。字太多张数太少装不下，
就把**整叠一起加高**（不会偷偷多给你一张），并在预览上方写明。
**导出前每一张都画出来给你看**，点一张选中它。

**纸** —— 内置四张（宣纸/米黄/牛皮/布纹）全是**代码画的**，不带任何素材，
外加一张纯黑。想用自己的信纸：按 **＋** 丢图片进来，或者用
[`tools/make-pack.py`](tools/make-pack.py) 打成素材包一次导入。

**墨色自动配** —— 换到浓色纸时，如果当前这支墨在新纸上的对比度低于 3.2（读不出来），
会自动换成对比最好的那支并告诉你一声。够读的话就不动你的选择。

**字** —— 自动探测系统里装了哪些字体，没装的灰掉。
**西文字体单独一档**，拼在中文字体前面，只接管字母和数字，汉字自动落回中文字体
（很多中文字体自带的拉丁字母是等宽的，英文看着像打字机，这一栏就是治它的）。

**版式预设** —— 内置摘录 / 日记 / 信件 / 竖排四套，点一下换整套外观。
调到满意可以起名存下来。**换版式不动你写的字。**

**字数不限** —— 题头、标题、出处都没有长度上限，太长会自己折行（竖排折成多列），
占位跟着实际行数走，不会冲出版心。

设置存在油猴里，**跨网站共享** —— 纸、字、墨、版式设一次，所有网站通用。

## 选中文字没反应？

**九成是这一页在你装脚本之前就开着了 —— 按 F5 刷新。**

还不行的话，在那一页点油猴图标 → **「拾句：自检」**，会弹一个框告诉你
脚本活没活、在不在 iframe 里、GM 权限有没有给到、系统里哪些字体能用。

> 如果油猴菜单里**连「拾句：自检」这一项都看不到**，说明脚本在这一页压根没跑起来
> （不是「跑起来了但按钮没冒」）。这两件事的修法完全不同：前者去查扩展页的
> 「允许用户脚本」开关和脚本自身的启用状态。

**字体装了却还是灰的** —— 要**完全退出浏览器再开**。Chrome 系在进程启动时
就把字体列表读死了，不会热加载。

## 字体

`fonts/` 里附了 10 款英文字体（全部 SIL OFL 或 Apache 2.0，可自由再分发），
每款的授权原文都在它自己的目录里。

中文字体本仓**不收录文件**，只给出处和授权结论 —— 见 [`docs/FONTS.md`](docs/FONTS.md)。
那份文档里也写清楚了「免费商用」和「可再分发」是两件不同的事，以及两款需要特别注意的字体。

## 信纸素材规格

想自己做纸的话：

| | |
|---|---|
| **尺寸** | 竖版 ≥ 2160×2700，横版 ≥ 2700×2160。卡片显示是一半，但导出是 2 倍图 |
| **比例** | 竖 4:5 / 横 5:4。别的比例也能用（按 cover 居中裁切） |
| **格式** | JPG / PNG / WEBP 都行 |

**最要紧的一条：纸必须「上下随便裁都不露馅」。** 内容多的时候卡片会一直往下长，
纸按 cover 铺满会被拉伸裁切。所以别放边框、装订孔、四角装饰、明显的构图中心
或者有方向感的渐变；纹理要**满幅均匀**。

另外：平均亮度建议 ≥ 78%（正文默认是黑字），局部对比克制 ——
强烈的污渍和做旧斑块会抢正文。
